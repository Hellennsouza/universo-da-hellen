UNIVERSO DA HELLEN — GITHUB PAGES
1. Envie o CONTEÚDO desta pasta para a RAIZ do repositório (não uma pasta dentro dele).
2. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
3. Em Custom domain informe universodahellen.com.br e salve.
4. No painel DNS do registrador, configure quatro registros A para @:
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
5. Para www, crie CNAME www -> Hellennsouza.github.io (se quiser www).
6. Remova registros A/AAAA/CNAME conflitantes de @ e www, respeitando outros serviços em uso.
7. Aguarde a propagação do DNS e a emissão do certificado; ative Enforce HTTPS quando disponível.
8. Verifique a aba Actions e Settings > Pages para erros de publicação.
OBS: o GitHub Pages publica HTML/CSS/JS, mas NÃO executa o aplicativo Python Streamlit.
