Sobre este simulador

Este laboratório interpreta comandos selecionados dos exemplos, como digitalWrite, analogWrite, delay, servo.write, lcd.print e Serial.println. Não compila todo o C/C++ Arduino.

Para editar ligações de componentes, utilizar bibliotecas completas e executar código em um microcontrolador emulado, use o simulador Wokwi. Você poderá copiar seu sketch deste laboratório para lá.
